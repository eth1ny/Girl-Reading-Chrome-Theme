# Girl Reading - Ethy

A quiet Google Chrome theme inspired by *Girl Reading* (1909) by American painter Edmund C. Tarbell. Warm umber, muted olive-brown, and soft ivory tones bring the painting's calm atmosphere to the browser.

## Theme information

- **Name:** Girl Reading - Ethy
- **Type:** Google Chrome theme
- **Version:** 1.0.2
- **Creator:** Ethy
- **Artwork:** *Girl Reading* (1909), Edmund C. Tarbell
- **New Tab background:** 2560 x 1440

## Artwork references

The original painting is in the public domain.

- [Museum of Fine Arts, Boston - Girl Reading](https://collections.mfa.org/objects/31346/girl-reading)
- [Palmer Museum of Art - Girl Reading](https://palmer.emuseum.com/objects/4920/girl-reading)

This is an independent, unofficial theme. It is not affiliated with, endorsed by, or sponsored by either museum.

## Compatibility

Designed for the desktop version of Google Chrome.

## Install locally

1. Open chrome://extensions in Chrome.
2. Enable **Developer mode**.
3. Select **Load unpacked**.
4. Choose this project folder.

## Remove the theme

Open Chrome **Settings > Appearance** and select **Reset to default**, or open chrome://extensions and remove the theme.
